## Debt neutralized

### Dependency direction

`application/use_cases/optimize_antenna.py` and
`application/use_cases/run_convergence_study.py` imported
`simulation/discretization.py`, an adapter-layer path, even though the module
is solver-independent and imports only the domain. The module moved to
`application/discretization.py`; the solver adapter now consumes it inward.
`tests/unit/test_architecture_boundaries.py` now guards domain, application,
importers, persistence, simulation, reporting, and presentation, and
allowlists the remaining UI adapter imports as a ratchet.

### Untrusted project files

`JsonProjectRepository` limited the compressed file but called
`gzip.decompress()` without a bound. A gzip bomb could therefore allocate an
unbounded payload. Loading now stops above 256 MB of expanded JSON and reports
`ProjectTooLargeError`. The compressed 64 MB limit and the 32 MB warning are
unchanged.

### Untrusted text imports

NEC-2, MMANA, and VNA imports read the complete selected file before parsing.
They now call `read_import_text()`, which rejects files above 16 MB before
decoding; the parser-specific row and character limits still apply.

### Documentation and packaging truth

- The `DOMAIN_MODEL.md` envelope example said `schema_version: 8` while the
  committed fixture is version 1. The example now shows version 1 and states
  that it is the migration fixture, not the current serialization.
- The `Development Status` classifier still said `2 - Pre-Alpha` after the
  1.0 truth pass changed the README to pre-1.0. It is now `4 - Beta`.
- `ARCHITECTURE.md` now lists the Qt-free `presentation/` package, the
  application simulation services, and the corrected adapter responsibilities.
  `DISPLAY_UNITS_SPEC.md` and ADR-0046 point at the current paths.
- The stale `F1` row (`LiveTuningDialog._finished` duplicate return) was
  removed: the current method has a single return per branch and both `mypy`
  unreachable-code checks pass.

### CI and documentation guards

- Documentation-only changes did not trigger CI even though the documentation
  tests exist. `docs/**` is now in both `push` and `pull_request` path filters.
- New guards cover every ADR in the index (and reject dead entries), SPDX
  headers on maintained Python sources, the version-1 example fixture, and the
  dependency-direction rules.

## Deferred technical debt

These are real but not release-blocking; each is a separate, reviewable
milestone rather than a QA sweep change.

1. **`ui/main_window.py` is still a god object.** At the start of the sweep it
   was 10,357 lines with 314 methods; the first follow-up extraction reduced it
   to 9,742 lines and 290 methods. `_build_ui` alone is still 775 lines.
   Candidate extractions are catalog creation, simulation orchestration,
   report/export actions, and project persistence/undo. This needs its own
   milestone and UI regression pass.
2. **Duplicated Qt worker lifecycles.** Ten dialogs plus the main window repeat
   the `QThread`/worker/lifecycle pattern (16 sites). A shared controller could
   remove duplication, but Qt teardown is sensitive and the current tests pass;
   do not change it as drive-by cleanup.
3. **Remaining UI adapter imports.** `ui/main_window.py` still imports
   `persistence.constants`, `simulation.nec2.export`,
   `simulation.nec2.solver`, and `simulation.preflight`. `ui/app.py` is the
   composition root and is allowed to build concrete adapters. The architecture
   test allowlists the four main-window entries so new leaks fail immediately;
   remove an entry when the matching use case/port exists.
4. **Manual desktop visual QA.** The U6 light/dark and font-scaling checklist
   is still manual. It is not a code defect and cannot be closed headlessly.
5. **Platform/reference coverage.** The Windows 3.11 UI suite remains excluded
   by ADR-0025, and the MMANA cross-check corpus is not committed, so it skips
   without the local reference data. Both are documented existing limits.

## Follow-up: first main-window extraction

The typed-family `SimulationSpec` builders moved from `ui/main_window.py` to
the Qt-free `application/simulation_specs.py`, the far-field pattern presets
moved to `application/pattern_resolution.py`, and the pattern-budget planner
moved to `application/pattern_planning.py`. Catalog and template routing moved
to `ui/catalog.py`, leaving project creation and template application in the
window. Export dialogs and writer dispatch moved to `ui/exporters.py`, and
VNA/NEC/MMANA import dialogs and parsing moved to `ui/import_actions.py`.
Project open/save workers, file pickers, progress dialogs, payload preparation,
and bundle-worker execution moved to `ui/project_io.py`; the autosave timers,
recovery storage, corrupt-file warning, and startup restore prompt moved to
`ui/recovery_actions.py`. The eight element-optimizer variable/build/band
dialogs moved to `ui/element_optimization_actions.py`. Project state, shared
form checks, parameter application, and simulation remain in the window. The
family, length, and synthesis dialog wrappers moved to
`ui/optimization_actions.py`. The slices fell from 10,357 to 7,573 lines and
from 314 to 243 methods. The final gate, including the 25-case typed-family
matrix, the pattern-planning tests, and explicit malformed MMANA/Touchstone
cases, is **4,282 passed, 1 skipped**. No schema, solver, or user-visible
behavior change.
