# Manual QA pass — 2026-11-15

- **Scope:** manual review of the end-fed, feed-line, matching, and report
  changes accumulated after `0.6.0`.
- **Result:** user-reported pass. No blocking visual, interaction, or
  readability issue was found.
- **Environment:** local desktop session on the development machine. Exact
  display size, platform scaling, and font settings were not recorded.

## Areas reviewed

| Area | What was checked | Result |
|---|---|---|
| End-fed editor | L/Pi/T topology selector, visible component fields, return-path selector, feedpoint choke, transformer model and loss selector | pass |
| Feed line | Catalog selection, RG-58A/RG-213 frequency-dependent table hint, manual edit back to Custom | pass |
| Matching precedence | Design-specific network, project override state, retained/active wording | pass |
| Reports | Design summary, construction sheet, total feed-chain loss row, topology-specific network rows | pass |
| Themes and scaling | Light/dark appearance and the application's normal text scaling on the reviewed screens | pass |

The one skip is the Windows-only console-hiding check on Linux. The full suite
ran with the local `NEC2C` solver and no Python warning was promoted to an
error.

## Residual manual QA

- A real-display pass on Windows and a second Linux display scaling are still
  recommended before publishing.
- Screenshots and exact platform/font details were not captured in this pass.
- Offscreen visual QA is not a substitute for checking real font rendering,
  high-DPI scaling, and platform window decorations.

## Decision

The manual pass is accepted for the `0.7.0` release candidate. The release
remains unsigned until project signing keys are configured.
